# TimeOnChrome — 产品需求文档 (PRD)

版本：1.7.0
更新：2026-04-21

---

## 1. 产品概述

**TimeOnChrome** 是一款面向家庭的 Chrome 时间管理扩展，帮助孩子合理安排上网时间，培养自律习惯。

### 核心理念

> 不是管控，而是助手。TimeOnChrome 不告诉孩子什么能用、什么不能用，而是帮助孩子记录、追踪、感知自己的时间使用情况，在关键节点给出友好提醒和选择。

**两个根本原则：**
1. **没有"白名单"，只有"学习网站清单"** — studyList 不是访问权限列表，是孩子认可的学习资源目录
2. **不是拦截，而是提醒** — 系统从不强制"阻止"孩子，而是在关键时刻提供时间管理建议和选项

---

## 2. 用户角色

| 角色 | 说明 | 主要界面 |
|------|------|---------|
| 孩子 | 日常使用 Chrome 上网，被辅助管理时间 | Popup（只读激励视图）、reminder.html（提醒页） |
| 家长（管理员）| 配置规则、查看统计、审核孩子行为 | Admin 面板、Web 控制台（Cloudflare Pages）|

## 3. 时间分类模型

### 3.1 三类时间

| 类型 | 触发条件 | 配额来源 | 说明 |
|------|---------|---------|------|
| **学习时间** | 学习模式 + studyList 域名 + active 心跳 | `dailyStudyQuota` | 有效学习，家长鼓励 |
| **休息时间** | 休息模式 + 任意域名 + active 心跳 | `dailyRestQuota` | 娱乐放松 |
| **待定时间** | compositeList 域名 + 任意模式 | `dailyUndeterminedQuota` | 性质待定，家长事后审核分流 |

**在线总时长** = 学习 + 休息 + 待定，受 `dailyOnlineQuota` 约束。

### 3.2 域名分类

| 列表 | 说明 | 时间归类 |
|------|------|---------|
| `studyList` | 学习网站（如 Khan Academy、教材在线） | 学习时间 |
| `compositeList` | 待定网站（如 Wikipedia、YouTube） | 待定时间 |
| `unsafeList` | 不适合访问的网站（如 TikTok、抖音） | 硬拦截，不计时 |
| 其他 | 未分类网站 | 休息时间 |

### 3.3 模式

| 模式 | 进入方式 | 行为 |
|------|---------|------|
| `study`（学习模式）| 手动切换 / 自动触发 | 访问非学习/非待定网站 → 提醒页 |
| `rest`（休息模式）| 手动切换 | 所有网站可访问，时间被记录 |

## 4. 功能需求

### 4.1 提醒系统（reminder.html）

提醒页取代旧版"拦截页"，根据触发场景显示不同内容和操作选项。

| 场景 | 触发条件 | 操作选项 |
|------|---------|---------|
| `unsafe` | 域名在 unsafeList | 仅「返回」（唯一硬拦截） |
| `schedule` | 当前时间在禁止上网时段外 | 仅「返回」 |
| `study_mode` | 学习模式 + 域名不在 studyList/compositeList | 📝 加入待定网站 / ☕ 切换休息模式 / ← 返回 |
| `quota_rest` | 休息配额用完 | ⏱ 向明天借时间 / 📚 切换学习模式 / 📊 查看详情 |
| `quota_study` | 学习配额用完 | ☕ 切换休息模式 / 📊 查看详情 |
| `quota_undetermined` | 待定配额用完 | 📚 切换学习模式 / 📊 查看详情 |
| `quota_online` | 在线总配额用完 | ⏱ 向明天借时间 / 📊 查看详情 |
| `quota` | 单域名配额用完 | ⏱ 向明天借时间 / 📊 查看详情 |

#### F-01 加入待定网站
- 孩子在学习模式下访问未分类网站，可点击「加入待定网站」
- 域名即时加入 `compositeList`，消耗 `dailyUndeterminedQuota`
- 同时触发云端事件 `composite_add`，**邮件通知家长**（每域名每小时最多 1 封）
- 家长登录控制台后审核，可将该域名的时间重分类为学习或休息

#### F-02 向明天借时间
- 孩子配额用完后可借用明天的休息配额（最多 60 分钟/次）
- 借出后当天立即可用，下周一前偿还
- 每天只能借一次（防循环）
- 周日不可借（防跨周边界问题）

### 4.2 时间配额

#### F-03 四档独立配额

| 配额字段 | 说明 | 默认 |
|---------|------|------|
| `dailyOnlineQuota` | 每日总在线时长上限 | 0（不限）|
| `dailyStudyQuota` | 每日学习时长上限 | 0（不限）|
| `dailyRestQuota` | 每日休息时长上限 | 120 分钟 |
| `dailyUndeterminedQuota` | 每日待定网站时长上限 | 60 分钟 |

达到上限后跳转对应提醒页；可通过「借时间」临时延长。

#### F-04 单域名配额
- 可对特定域名单独设置每日使用上限
- 超出后跳转 `quota` 提醒页

#### F-05 周配额（Rest 周配额）
- `weeklyRestQuota`：限制每周总休息时长
- 超出后 `quotaState.weeklyRestLocked = true`，休息模式受限

### 4.3 Mode Service 自动切换

#### F-06 触发条件
- 当前处于 `rest` 模式
- 活跃 Tab 是 `studyList` 或 `compositeList` 中的域名
- Chrome 访问事件携带当前 tab/url/foreground 事实
- `Mode Service` 立即执行目标模式迁移，并向目标 tab 投递页内提示

#### F-07 稳定期规则
| 情况 | 行为 |
|------|------|
| 刚进入 Study/Composite 未满 60 秒访问 Rest target | 自动回 Rest，只显示页内提示 |
| Study/Composite 已稳定后访问 Rest target | 进入 Reminder |
| 手动模式切换 | 通过 `REQUEST_MODE_CHANGE` 进入同一 Mode Service 提交流程 |

### 4.4 时间统计

#### F-08 事件驱动注意力引擎（v1.7.0 新架构）
- content.js 每 10 秒发送 HEARTBEAT 作为信号源
- background.js 通过 `signal.js` 接收信号，80ms micro-batching 合并窗口
- `context.js` 构建上下文（lastActiveTabId、domain、isFocused）
- `state.js` 解析状态：
  - `ACTIVE`：用户交互中，页面可见 → 计为 1
  - `BACKGROUND_ACTIVE`：后台活跃 → 计为 1
  - `PASSIVE`：媒体播放中 → 计为 0（不计入时长）
  - `IDLE`：无交互/无域名 → 计为 0
- 无域名时返回 IDLE（防止 `chrome://` 页面污染）

#### F-09 计时规则（事件驱动模型）

| 状态 | 计入时长 | 说明 |
|------|---------|------|
| ACTIVE | +1s | 用户有键鼠操作，页面可见 |
| BACKGROUND_ACTIVE | +1s | 后台活跃（如音乐播放但用户在其他标签操作） |
| PASSIVE | 0 | 媒体播放中，用户无交互 |
| IDLE | 0 | 无域名或无交互 |

**多标签页去重**：同一域名的多个标签页不会重复计时，通过 context 去重

**SW 恢复机制**：Service Worker 重启后，`recovery.js` 自动从事件日志重建会话，90s 休眠检测阈值

**心跳机制保留**：content.js 仍每 10 秒发送 HEARTBEAT 作为信号源，但计时不再依赖心跳累加，而是事件驱动

### 4.5 时间段管控

#### F-10 允许上网时间段
- 按星期分别设置允许上网时段
- 时段外访问任何网站 → `schedule` 提醒页（仅返回）

### 4.6 云同步与多设备

#### F-11 账户与设备绑定
- 家长注册账号（email + 密码，HMAC-SHA256 JWT）
- 每台设备生成唯一 `device_token`，绑定到家长账号
- 设备信息：OS 类型 + 4 位随机码（如 `Windows · Chrome · A3F2`）

#### F-12 配置同步
- 每次打开 Chrome 时 pull 云端配置（版本号保护，本地配额状态不被覆盖）
- **终端只读拉取，不推送配置**（家长控制台是唯一配置修改入口）
- 本地保护字段（不被云端覆盖）：`quotaState`、`lockedDomains`

#### F-13 会话上传与审核
- 每次会话结束时，session 数据上传到 R2
- 家长在 Web 控制台查看待定会话，可将其重分类为「学习」或「休息」
- 孩子可对家长的判定提起申诉

#### F-14 跨设备配额同步
- `GET /device/quota-state` 聚合接口，返回多设备汇总的配额使用情况
- 扩展每次同步时拉取并合并到本地 `quotaState`

#### F-15 家长事件通知（邮件）
触发邮件通知的事件（每类事件每域名每小时最多 1 封）：

| 事件 | 触发时机 |
|------|---------|
| `composite_add` | 孩子将网站加入待定列表 |
| `unsafe_block` | 孩子尝试访问不安全网站 |
| `quota_locked` | 配额用完锁定 |
| `temp_allow` | 孩子申请临时放行（旧版，保留兼容）|

### 4.7 管理员安全

#### F-16 密码保护
- 管理面板需要密码登录
- 密码以 SHA-256 哈希存储（本地），账号密码 HMAC-SHA256（云端）

#### F-17 配置完整性校验
- 配置数据附带 HMAC 哈希，防手动篡改

#### F-18 设备监控开关
- `monitoring_enabled` 字段：家长可在控制台临时关闭某设备的监控
- 关闭后扩展跳过所有提醒和拦截逻辑

## 5. 界面

### Popup（孩子视图）
- 只读激励视图：今日学习/休息时间、进度条
- 当前模式显示
- 一键切换学习/休息模式
- 配额剩余提示

### Admin 面板（家长视图，密码保护）
- **今日使用**：学习/休息/待定时长、配额进度
- **访问规则**：studyList、compositeList、unsafeList 管理，时间段配置
- **使用分析**：域名统计、历史趋势、热力图
- **本机设置**：设备信息、同步状态、密码修改

### Web 控制台（家长，需登录）
- 多设备管理（列表/重命名/解绑/监控开关）
- 待定会话审核（学习 vs 休息分类）
- 配置变更日志（最近 100 条）
- 账户管理（改密、删档）

---

## 6. 非功能需求

| 需求 | 说明 |
|------|------|
| 统计数据保留 | 最近 30 天（本地），R2 长期归档（云端）|
| Service Worker 保活 | 每 30 秒 keepalive alarm，防 SW 休眠 |
| 心跳间隔 | 10 秒，hidden/idle 不发送 |
| 自动切换延迟 | 默认 90 秒，可配置 |
| 邮件去重 | KV 存储，同类事件每域名每小时最多 1 封 |
| 每日重置 | 每天本地时间 00:00 重置配额状态 |

---

## 7. 已知限制

- 孩子可通过 chrome://extensions 禁用扩展绕过所有管控（建议配合系统级家长控制）
- declarativeNetRequest 重定向无法动态传参 → unsafeList 拦截改用 webNavigation + reminder.html 实现
- 邮件通知依赖 Resend API Key 配置，未配置时静默跳过
