# Session 和 ChangeLog 功能设计文档

## 一、访问会话记录（Visit Sessions）

### 设计理念
**统计定位，而非监督定位**：
- 只记录域名，不记录 URL 或页面标题（隐私友好）
- 记录时间段和行为分布，帮助分析使用模式
- 保留 14 天，用于近期行为回顾

### 数据结构

```javascript
VisitSession {
  id: string,           // 唯一标识
  domain: string,       // 访问的域名（隐私友好）
  date: string,         // 日期 YYYY-MM-DD
  startAt: number,      // 开始时间戳
  endAt: number,        // 结束时间戳
  duration: number,     // 持续秒数
  activeTime: number,   // 主动交互秒数
  passiveTime: number,  // 被动观看秒数
  visibleTime: number,  // 可见但无交互秒数
  endReason: string     // 结束原因: 'hidden' | 'new_session' | 'blocked' | 'timeout'
}
```

### 触发逻辑

**开始会话：**
- 收到某域名的第一个心跳（页面可见）

**更新会话：**
- 每次心跳更新活跃时间
- 记录 active/passive/visible 分布

**结束会话：**
- 页面隐藏（hidden）
- 导航到新域名（结束旧会话，开始新会话）
- Tab 关闭（心跳超时 12 秒）
- 被拦截（规则触发）

**过滤规则：**
- 少于 10 秒的会话不保存（过滤误触和跳转中间页）

### 存储策略

- **存储位置**：`chrome.storage.local` - `visit_sessions` 键
- **保留时长**：14 天
- **最大条目**：500 条（防止极端情况）
- **清理时机**：每天自动清理 + 每次保存时过滤

### 查询 API

```javascript
// 获取最近 N 天的访问会话
const sessions = await sendMsg({ type: 'GET_VISIT_SESSIONS', days: 7 });
```

### 使用场景

**对孩子展示：**
- "你今天有 3 次专注学习时段，平均每次 25 分钟"
- "下午 2-3 点是你最高效的时间"

**对家长展示：**
- 查看孩子的上网模式（时间分布、网站偏好）
- 了解自动切换的触发情况

## 二、配置变更日志（ChangeLog）

### 设计理念

**透明性原则**：
- 所有规则变更都记录，让孩子知道限制从何而来
- 用人类可读的语言，而非技术术语
- 家长和孩子看到同样的历史（信息对称）

### 数据结构

```javascript
ChangeLogEntry {
  ts: number,           // 时间戳
  date: string,         // 日期 YYYY-MM-DD
  action: string,       // 动作类型
  target: string,       // 操作对象
  details: string,      // 人类可读描述
  before: any,          // 变更前值（可选）
  after: any            // 变更后值（可选）
}
```

### 动作类型

| 动作 | 描述 | 示例 |
|------|------|------|
| `add_to_studylist` | 添加到学习清单 | 将 khanacademy.org 添加到学习网站清单 |
| `remove_from_studylist` | 从学习清单移除 | 将 baidu.com 从学习网站清单移除 |
| `add_to_allowlist` | 添加到允许清单 | 将 music.163.com 添加到允许网站清单 |
| `remove_from_allowlist` | 从允许清单移除 | 将 bilibili.com 从允许网站清单移除 |
| `change_daily_quota` | 修改每日配额 | 每日上网时间限制从 60 分钟改为 90 分钟 |
| `change_schedule` | 修改时间段 | 修改了允许上网时间段设置 |
| `toggle_enabled` | 启用/停用 | 启用了家长守护 / 暂停了家长守护 |
| `toggle_auto_switch` | 切换自动模式 | 旧自动切换开关事件，当前 Mode Service 不再使用 |
| `manual_switch_to_study` | 手动切学习 | 手动切换到学习模式 |
| `manual_switch_to_rest` | 手动切休息 | 手动切换到休息模式 |
| `auto_switch_to_study` | 自动切学习 | 系统自动切换到学习模式 |
| `auto_switch_to_rest` | 自动切休息 | 系统自动切换到休息模式 |

### 存储策略

- **存储位置**：`chrome.storage.local` - `guardian_changelog` 键
- **保留条数**：最近 100 条（约 3-6 个月，取决于变更频率）
- **清理策略**：只保留最近 100 条，旧的自动丢弃

### 查询 API

```javascript
// 获取最近 N 条变更日志
const logs = await sendMsg({ type: 'GET_CHANGELOG', limit: 50 });
```

### 展示示例

**对孩子：**
```
📜 最近变更
• 昨天 20:15 - 妈妈把每天的上网时间改成了 90 分钟
• 昨天 19:30 - 把 Khan Academy 加到了学习清单
• 今天下午 14:20 - 系统自动切换到学习模式（检测到你在学习）
• 今天下午 13:45 - 你手动切换到了休息模式
```

**对家长：**
```
📜 配置变更历史
• 2024-01-15 20:15 - 修改每日配额: 60 → 90 分钟
• 2024-01-15 19:30 - 添加学习网站: khanacademy.org
• 2024-01-15 14:20 - 自动切换触发（访问学习网站超过 120 秒）
• 2024-01-15 13:45 - 手动模式切换: study → rest
```

## 三、隐私与信任设计

### 1. 数据最小化

**Session 记录：**
- ✅ 记录：域名、时间段、行为分布
- ❌ 不记录：URL、页面标题、搜索关键词、输入内容

**ChangeLog 记录：**
- ✅ 记录：配置变更、时间、操作者
- ❌ 不记录：密码、浏览历史、个人身份信息

### 2. 透明展示

- 孩子和家长看到**同样的** Session 和 ChangeLog 数据
- 没有"家长专用"的隐藏信息
- 所有规则变更都有时间戳和说明

### 3. 可控性

- Session 功能可以关闭（保留汇总统计）
- ChangeLog 始终开启（保证透明度）
- 数据只在本地存储，不上传云端

### 4. 统计而非监督

强调"了解使用模式"而非"监控一举一动"：
- "你在学习模式下平均每次专注 30 分钟"
- "下午 2-4 点是你最高效的时间段"
- "这周你有 5 次自动切换到学习模式"

## 四、存储量估算

### Session 存储

- **单条大小**：约 150 字节
- **每天数量**：50-200 条（取决于上网频率）
- **14 天总量**：约 7,000-28,000 条
- **存储占用**：约 1-4 MB

### ChangeLog 存储

- **单条大小**：约 200-500 字节（取决于详情长度）
- **100 条总量**：约 20-50 KB

### 总计

- **峰值占用**：约 4.5 MB（在 5 MB 限制内）
- **建议**：Session 保留 14 天，更早的只保留按天汇总

## 五、未来扩展

### 可能的增强

1. **使用模式分析**
   - "你通常在晚上 8-9 点学习效果最佳"
   - "这周你的学习时段比上周增加了 20%"

2. **趋势图表**
   - 每日学习/休息时长趋势
   - 网站偏好分布饼图
   - 高效时段热力图

3. **导出功能**
   - 导出为 CSV/JSON 进行外部分析
   - 生成周报/月报

4. **智能建议**
   - "根据你的模式，建议把数学学习安排在下午"
   - "你已经连续学习 45 分钟了，建议休息一下"
