## 1. UI 页面清单

| 页面 | 文件路径 | 用途 | 当前尺寸/环境 |
|------|---------|------|--------------|
| **Popup（孩子侧弹窗）** | `popup/popup.html` + `popup.js` | 孩子查看今日时长、切换模式、借用时间 | 固定宽度 320px，Chrome 扩展弹窗 |

## 2. UI 总体风格定位

### 2.1 设计语言

- **风格**：清新、柔和、教育友好型
- **主色调**：薄荷绿（#00b894）—— 传递积极、健康、成长感
- **辅助色**：暖橙（#f59e0b）用于提醒/警告，红色（#ef4444）用于危险/锁定
- **背景**：极淡的绿色灰（#f0faf6），降低视觉疲劳
- **卡片**：纯白 + 极淡绿边框，营造层次感
- **无锐利边角**：大量使用 8px-24px 圆角

### 2.2 跨页面一致性现状

| 维度 | 现状 | 问题 |
|------|------|------|
| 颜色 Token | 5 个页面均使用相似的 CSS 变量名，但 bind.html 未使用 CSS 变量 | bind.html 使用硬编码色值 |
| 字体栈 | 统一使用 `-apple-system, 'Segoe UI', sans-serif` | 一致 ✅ |
| 圆角规格 | 8px / 10px / 14px / 18px / 20px / 24px 混用 | 未统一标准 |
| 阴影 | bind.html 有 `0 4px 24px rgba(0,0,0,0.08)`，其他页面几乎无阴影 | popup 缺少阴影层次感 |
| 间距 | 以 4px / 8px / 12px / 16px / 20px / 24px / 32px / 40px 为主 | 基本合理，但未文档化 |

网站管理主分类不是内容分类，而是 TimeOnChrome 的管理策略分类：学习网站、复合网站、受限娱乐网站、黑名单网站、特殊网站、已使用未归类网站。Qustodio 风格内容分类只作为系统配置管理的辅助元数据。特殊网站和已使用未归类网站都是左侧策略目录项，不是来源筛选项，也不应附加在普通策略页面顶部。

**系统网站配置区规则：**
- 系统配置区在右侧目录中显示为“系统网站配置-分类管理”，不是独立一级页面或独立 tab；
- 系统配置项按 `siteCatalog.contentCategory` 分组成 Qustodio 风格内容分类，可折叠、可搜索；
- 系统默认网站库应覆盖全部系统配置项；只有缺少目录元数据且无法由 fallback catalog 补齐的系统配置项才归入“未标注分类”；
- 系统配置项显示受管来源标记；
- 管理员可点击系统配置项，同时编辑“内容分类”和“管理策略”，并通过全局确认保存到系统访问配置，影响所有 profile；
- 非管理员可查看系统配置项，但分类操作禁用或由后端返回 `SYSTEM_ACCESS_CONFIG_ADMIN_REQUIRED`；
- 配置文件区使用统一“访问管理配置文件”入口，不再拆成多个导入/导出按钮；默认勾选“用户配置”和“系统配置”。
- 用户配置包含当前档案的网站自定义、精确规则、审核记录、配额和时间段；系统配置包含全局系统网站库和 `siteCatalog`。
- 导入后使用同一个差异确认面板，按“用户配置 / 系统配置”分组；系统配置差异需要管理员权限和全局影响确认。

**用户自定义配置区规则：**
- 用户自定义配置项可添加、删除、移动分类；云端管理员可在单项后点击“添加到系统配置”，将该网站提升为系统网站配置-分类管理并从当前档案用户自定义配置中移除；
- 顶部“添加到当前策略”入口只新增用户自定义配置网站；空输入、非法域名、当前策略重复、跨策略重复都必须显示 toast，不得静默失败；
- 添加入口发现网站已属于其他策略时，不直接移动，提示用户点击已有网站的“归为…”操作或通过系统网站配置-分类管理编辑系统项；
- 移动分类只在当前 profile 的 custom list 间迁移；
- 用户配置导入导出包含用户自定义配置列表、已批准精确规则、审核记录、配额和时间段。


**云端特殊网站规则：**
- 云端访问管理页的特殊网站区第一版展示 YouTube，使用单一规则列表，不使用根域卡片加说明卡片；
- `youtube.com` 根域作为一行展示，管理属性为受限娱乐，不能直接改为学习或复合；
- 每个已同步特殊对象规则作为一行展示对象链接、对象类型、管理属性、来源和操作；
- 云端家长控制台可把具体视频、播放列表、频道规则在学习 / 复合 / 受限娱乐 / 黑名单之间变更，保存后同步到设备。
**本地 Admin 访问管理（只读）：**
- 本地 Admin 的访问管理与云端控制台保持同一视觉语言，但必须只读展示当前生效配置；不得出现添加、保存、导入、导出、审批或编辑分类入口；
- 本地访问管理页内 tab 为“网站管理 / 时间配额 / 时间段管理 / 网站归类记录”，第四项不是配置文件管理；

- 点击 `[+ 添加时段]` 在当前单元格内展开时间输入（`start` — `end`）

## 20.5 设备健康状态（Pages 家长控制台）

设备健康状态与监控开关状态是**两个独立概念**，UI 必须分开展示。

### 20.5.1 状态定义

| 状态 | 条件（last_seen 距今） | Badge 文案 | CSS 类 | 颜色 |
|------|------------------------|------------|--------|------|
| 在线 | ≤ 15 分钟 | 在线 | `.device-status.online` | 绿色 |
| 心跳延迟 | 15–60 分钟 | 心跳延迟 | `.device-status.recent` | 橙色 |
| 可能失联 | > 60 分钟 | 可能失联 | `.device-status.offline` | 灰色 |
| 从未连接 | 无 last_seen | 从未连接 | `.device-status.offline` | 灰色 |

### 20.5.2 文案规则

**必须使用概率性文案，不得断言扩展已禁用或已移除。**

- ✅ 正确：`可能失联`、`设备未上报`、`设备可能离线或 Chrome 未运行`
- ❌ 禁止：`扩展已被禁用`、`扩展已被移除`、`离线`（作为确定性结论）

**“可能失联”状态的 tooltip 文案：**
> 超过 1 小时未收到心跳。可能原因包括：设备离线、Chrome 未运行、网络中断，或扩展被禁用/移除。请检查设备。

### 20.5.3 监控开关（独立显示）

设备健康状态旁边必须独立显示监控开关状态：

| 监控状态 | 图标 | 文案 | 操作 |
|----------|------|------|------|
| 监控中 | 🖥️ | 监控中 | 点击停用 |
| 已停用 | 😴 | 已停用 | 点击启用 |

监控开关不影响心跳上报。即使监控已停用，扩展仍继续发送 cloudHeartbeat，设备健康状态仍按 last_seen 判断。

### 网站添加校验规则

添加或移动网站前应按主站等价域名检查重复：`example.com`、`www.example.com`、`m.example.com` 视为同一主站入口。命中已定义主站时显示：`该网站属于已定义的主站入口，不能单独归为学习网站。`
