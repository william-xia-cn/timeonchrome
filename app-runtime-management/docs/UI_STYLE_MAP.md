# App Runtime 应用管理 UI 约定

ARM-D-012：五导航/五目录和管理面板保持。目录范围 select 提供主要应用、已安装未使用、使用未归类证据、完整发现；主要应用排除明确隐藏组件，运行证据不被隐藏角色豁免。安装未使用可归类，友好名称回退明确提示。盘点状态显示批次/来源失败及未验证用户，不能以行数冒充整机完整；不展示内部身份或路径。

ARM-D-011：保持使用统计、访问管理、应用管理、设备管理、系统管理五项导航及五分类目录，无二级页签。

应用管理工具栏提供“确定性应用列表”和“分类规则管理”；分别打开独立可滚动面板，移动端面板全屏、关闭操作可达。产品列表管理类型、孩子分类、确认范围、变种及解除关联；规则面板展示条件/排除/自动或建议/结果/来源/启用状态。

规则包导入先显示新增/修改/冲突/命中应用/目标孩子，逐项批准，不自动覆盖明确配置。目录显示安装未使用、预配置未发现、使用过未发现、分类保存/设备应用/建议状态；不显示原始身份、路径、SID、凭据。疑似游戏/视频优先，完整已发现清单可查看。系统日志和访问配置保持不变。
