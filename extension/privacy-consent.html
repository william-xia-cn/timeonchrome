TimeOnChrome 隐私与数据使用说明

请先阅读并同意，再启用计时、访问管理、云同步和设备恢复。

显著披露：TimeOnChrome 会处理浏览使用元数据，用于家庭上网时间管理、网站归类、访问规则、使用统计、提醒、诊断和可选云同步。

在你点击下方同意按钮之前，TimeOnChrome 不会启动新的网页计时落账、媒体计时、云同步、诊断日志上传或 Chrome 身份恢复。

会处理哪些数据

  • 访问域名或家长配置的管理对象、开始/结束时间、使用时长、当前模式和访问控制结果。
  • 网站归类申请、家长审批结果、配额、时间段和访问规则配置。
  • 设备绑定状态、同步状态、诊断日志、媒体使用元数据和可选云同步所需的账户/会话状态。
  • identity.email 仅用于调用 chrome.identity.getProfileUserInfo()，帮助 macOS / Windows 扩展重装后恢复原设备绑定；不使用 Google OAuth，不保存 Google token，不保存原始 Chrome 身份标识。

何时本地记录，何时上传云端

同意后才开始在本机处理和保存核心计时、访问管理和诊断数据；绑定云端后才会上传配置、使用记录、申请、设备和诊断摘要到 TimeOnChrome 云端服务。

谁可以看到，如何共享

绑定云端后，与该子用户档案关联的家长或监护人可以在云端控制台查看和管理规则、设备状态、网站归类申请、使用统计和诊断信息。云端基础设施由 Cloudflare 提供。TimeOnChrome 不出售用户数据，不用于广告，也不与广告平台或数据经纪商共享。

不会收集的内容

TimeOnChrome 不收集网页正文、表单输入、聊天或评论内容、密码、支付信息、网站 Cookie、Google OAuth token 或原始 Chrome profile 身份标识。

停止和删除

你可以禁用或卸载扩展来停止后续本地记录。家长可以在云端解绑设备以停止同步，也可以删除或替换档案配置，并通过支持渠道请求删除云端数据。
